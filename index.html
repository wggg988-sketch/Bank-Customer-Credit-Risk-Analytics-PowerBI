Excel Bo'yicha Asosiy Topilmalar, Xulosa va Tavsiyalar

Asosiy topilmalar:

  • Eng ko'p mijozlar Toshkent shahri va Toshkent viloyatida joylashgan.
  • Mijozlarning asosiy qismi 25–44 yosh oralig'ida (eng faol kredit oluvchilar).
  • Kredit portfeli bo'yicha Kapitalbank, Ipoteka-bank, Hamkorbank yetakchilik qilmoqda.
  • Mijozlarning katta qismi (68-70%) mobil ilova va internet-bankingdan foydalanadi.
  • Muddati o'tgan qarzlar foizi 8% atrofida, past daromadli segmentda xavf yuqori.

Qisqa xulosa va Tavsiyalar:

Qisqa xulosa: Bank mijozlari asosan yosh va o'rta yoshdagi, shaharlik va raqamli xizmatlarga moyil insonlardan iborat. Kredit berishda daromad darajasi va skoringiga e'tibor qaratish zarur.

Tavsiyalar:

  • Yosh va o'rta yoshdagi mijozlar uchun maxsus kredit mahsulotlarini ko'paytirish.
  • Raqamli xizmatlardan foydalanmayotgan mijozlarni mobil ilovaga jalb qilish.
  • Past kredit reytingiga ega mijozlar uchun xavfni monitoring qilish mexanizmlarini kuchaytirish.

1. Jins va 2. Viloyatlar bo'yicha so'rovlar

-- Jinsi bo'yicha mijozlar soni
SELECT jinsi, COUNT(*) AS soni 
FROM mijozlar 
GROUP BY jinsi;
-- Natija: Ayol: 2000, Erkak: 2000

-- Viloyatlar bo'yicha kamayib borish tartibi
SELECT viloyat, COUNT(*) AS mijozlar_soni 
FROM mijozlar 
GROUP BY viloyat 
ORDER BY mijozlar_soni DESC;

3. Yosh guruhi (CASE) va 4. Kredit olganlar foizi

-- Yosh guruhlari bo'yicha tartiblash
SELECT "Yosh_guruxi", COUNT(*) AS soni
FROM mijozlar
GROUP BY "Yosh_guruxi"
ORDER BY CASE "Yosh_guruxi"
    WHEN '18-24' THEN 1 WHEN '25-34' THEN 2
    WHEN '35-44' THEN 3 WHEN '45-54' THEN 4
    WHEN '55+' THEN 5 END;

-- Kredit olgan mijozlar foizi
SELECT kredit_mavjud, COUNT(*) AS soni,
       ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM mijozlar), 1) AS foiz
FROM mijozlar GROUP BY kredit_mavjud;
-- Yo'q: 2330 (58.3%), Ha: 1670 (41.8%)

5. Banklar bo'yicha kredit va 6. Raqamli mijozlar

-- Banklar va jami kredit summasi (Top 10)
SELECT bank, COUNT(*) AS mijozlar_soni,
       SUM(kredit_summasi_uzs) AS jami_kredit,
       ROUND(AVG(kredit_summasi_uzs)) AS ortacha_kredit
FROM mijozlar WHERE kredit_mavjud = 'Ha'
GROUP BY bank ORDER BY jami_kredit DESC LIMIT 10;

-- Raqamli mijozlar soni va foizi
SELECT "Raqamli_mijoz", COUNT(*) AS soni,
       ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM mijozlar), 1) AS foiz
FROM mijozlar GROUP BY "Raqamli_mijoz";
-- Raqamli: 3448 (86.2%), An'anaviy: 552 (13.8%)

7. Umumiy portfel xulosasi

SELECT 
    COUNT(mijoz_id) AS jami_mijozlar,
    COUNT(CASE WHEN kredit_mavjud = 'Ha' THEN 1 END) AS kredit_olganlar_soni,
    SUM(kredit_summasi_uzs) AS jami_kredit_portfeli,
    SUM(depozit_summasi_uzs) AS jami_depozit_portfeli,
    ROUND(AVG("o'rtacha_oylik_daromad_uzs"), 0) AS ortacha_daromad_uzs,
    ROUND(AVG(kredit_reytingi), 0) AS ortacha_kredit_skori
FROM mijozlar;
-- 4000 | 1670 | 50431445138 UZS | 10085836942 UZS | 6910380 | 618

8. Kredit turlari, foiz stavkalari va kredit yuklamasi

SELECT kredit_turi, COUNT(mijoz_id) AS shartnomalar_soni,
       SUM(kredit_summasi_uzs) AS jami_kredit_summasi,
       ROUND(AVG(yillik_foiz_stavkasi)::numeric, 2) AS ortacha_yillik_foiz,
       ROUND(AVG("Kredit_yuklamasi_foiz")::numeric, 2) AS ortacha_kredit_yuki_foiz
FROM mijozlar WHERE kredit_mavjud = 'Ha'
GROUP BY kredit_turi ORDER BY jami_kredit_summasi DESC;

9. Mobil ilova va Internet Banking tranzaksiyalari

SELECT mobil_ilova_foydalanadi, internet_banking,
       COUNT(mijoz_id) AS mijozlar_soni,
       ROUND(AVG(oxirgi_oy_tranzaksiyalar_soni), 1) AS ortacha_tranzaksiyalar_soni,
       SUM(oxirgi_oy_tranzaksiya_hajmi_uzs) AS jami_tranzaksiya_hajmi_uzs
FROM mijozlar
GROUP BY mobil_ilova_foydalanadi, internet_banking
ORDER BY jami_tranzaksiya_hajmi_uzs DESC;

Har bir viloyatda eng katta kredit olgan Top-3 mijozlar (DENSE_RANK Window Function)

WITH ViloyatReyting AS (
    SELECT mijoz_id, "to'liq_ism", viloyat, kredit_turi, kredit_summasi_uzs,
           DENSE_RANK() OVER(PARTITION BY viloyat ORDER BY kredit_summasi_uzs DESC) AS orin
    FROM mijozlar WHERE kredit_mavjud = 'Ha'
)
SELECT viloyat, orin, mijoz_id, "to'liq_ism", kredit_turi, kredit_summasi_uzs
FROM ViloyatReyting
WHERE orin <= 3 ORDER BY viloyat, orin;
